# BAROGO_HCR_DEMO

허브 컨트롤룸(HCR) 모바일 앱 시연 자료. 본편 30분 + 질의응답 10분, 허브·총판 관리자 대상 실기기 미러링 시연을 전제로 만들었다.

**바로 보기 → https://jaekanglee.github.io/BAROGO_HCR_DEMO/**

## 문서

| 파일 | 용도 |
|---|---|
| `2026-09-02-map-list-control-demo-outline.html` | **시연 개요** — 진행 순서와 핵심 메시지의 뼈대. 왜 만들었나 · 기대효과 · 지도관제 흐름(화면 목업/배차 경로 다이어그램) · 예상 질문. 실제 스크린샷 포함, 클릭하면 크게 보인다 |
| `2026-09-02-map-list-control-demo-script.html` | **시연 대본** — 조작과 읽을 문장을 단계별로 짝지은 전체 대본. 부록에 지연 개념·설정 기준 설명 |

발표 준비는 개요 하나면 되고, 대본은 문장까지 필요할 때 참고한다.

## 스크린샷

번호 순서가 곧 시연 순서다.

- `001~015` 지도관제 — 상점 모드(상점목록 → 배차) · 라이더 모드 · 지도 설정
- `016~018` 목록관제 — 접수 탭에서 라이더 배차까지
- `019~028` 마이페이지 — 상점·라이더 관리, 운행 설정, 배달 내역, 자동 지원금 등

모두 테스트 데이터다.
